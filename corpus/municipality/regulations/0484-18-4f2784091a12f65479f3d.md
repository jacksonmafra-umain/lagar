Eskilstuna kommun

Avgifter för Eskilstuna bibliotek

Förseningsavgift: 0 kr per dag för lånad bok/övrig media. Snabblån bok och tv-spel: 0 kr per dag (max antal lån per gång 2 st) Barn upp till 18 år betalar ingen förseningsavgift. Porto- och expeditionsavgift för utsänd faktura: 50 kr Fjärrlån inom Sverige: 0 kr

Kopia fjärrlån: 0 kr

Avgift för att ersätta förkommet lånekort vuxen: 0 kr Avgift för att ersätta förkommet lånekort barn: 0 kr Förkommen eller förstörd bok/övrig media ersätts med faktisk kostnad. Om uppgift om faktiskt kostnad saknas gäller dessa schablonbelopp: Vuxenbok: 300 kr

Barnbok: 150 kr

Tidskrifter: 75 kr

Film: 500 kr

Teve- eller dataspel: 800 kr

Förkommet eller förstört fjärrlån: faktisk kostnad

Barn upp till 18 år betalar inte ersättningsavgifter. Vid skuld över 100 kronor eller icke-återlämnade böcker kvar på bibliotekskontot, behöver den/de regleras/återlämnas innan nya bibliotekslån kan ske.

Avgifterna gäller från den 1 januari 2027.
