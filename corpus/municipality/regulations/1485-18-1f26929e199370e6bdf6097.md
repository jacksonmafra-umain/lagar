Uddevalla kommuns författningssamling

Felparkeringsavgifter Uddevalla Kommun

Följande avgifter ska gälla vid olovlig parkering på allmän plats:

400 kronor vid parkering i strid mot bestämmelser om avgift, tidsbegränsning eller parkeringsskiva.

600 kronor vid parkering där förbud mot att parkera fordon gäller samt vid stannande eller parkering:

På laddplats

På parkeringsplats där endast visst fordonsslag eller viss trafikantgrupp får parkera, förutom på särskilt utmärkt parkeringsplats för rörelsehindrad.

I terräng

Mot färdriktningen

900 kronor vid stannande eller parkering där förbud mot att stanna eller parkera fordon gäller, förutom vid stannade eller parkering

På laddplats

På parkeringsplats där endast visst fordonsslag eller viss trafikantgrupp får parkera

I terräng

Mot färdriktning

1300 kronor vid stannande eller parkering utan tillstånd på särskilt utmärkt parkeringsplats för rörelsehindrad.
