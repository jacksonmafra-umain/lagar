# lagar

Swedish laws, case law, EU law, municipal regulations and public services as
Markdown, one file per norm, with a static JSON API and Compose Multiplatform
apps for Android, iOS and the web.

- Web app: <https://grundlagar.vercel.app/app/> (landing page at <https://grundlagar.vercel.app>)
- API: <https://jacksonmafra-umain.github.io/lagar/api/v1/index.json> ([contract](docs/api.md))

## What the app covers

The app runs on Android, iOS and the web, in Swedish and English, light and dark.
It is anonymous: bookmarks and settings stay on the device.

- Onboarding: welcome, scope choice (Nationell, Region, Kommun) and optional county and kommun
- Utforska: the home screen for the chosen scope, with key laws and per-layer entry points
- Search and advanced search over the per-layer search index
- Hierarki: the normative hierarchy, from the fundamental laws down to municipal regulations
- Document reader: legal text by section, table of contents, amendment list, cross-reference links, notes and bookmarks per section
- Sparade: saved documents
- Drawer, scope switch and settings (language, theme, main focus)
- Tjänster (public services) is a placeholder until the corpus has services

Screen-by-screen status is in [docs/screens.md](docs/screens.md).

## Repository layout

- `corpus/` - one YAML-fronted Markdown file per norm
- `collector/` - Python collectors that build the corpus from official sources
- `api/` - generator for the static JSON API served on GitHub Pages
- `app/` - Compose Multiplatform app (Android, iOS, web)
- `landing/` - static landing page (Swedish and English), deployed to Vercel with the web app
- `docs/` - architecture, API contract and decision records
- `design/` - design exports and references
